# Generic pantry photo credits

Square-cropped WebP staples for FridgeForge pantry tiles. Sources are
**royalty-free / public-domain / clearly licensed** only (no Google Images
scraping, no copied brand packaging for generics). Brand product art still
comes from Open Food Facts at runtime when a barcode or branded name wins.

## Licenses

- **Wikimedia Commons** — files used under their stated licenses (Public Domain,
  CC0, CC BY, or CC BY-SA as marked on each Commons file page). Prefer PD /
  Evan-Amos food photography and other Commons commodity photos.
- **Unsplash** — [Unsplash License](https://unsplash.com/license): free to use
  commercially, including modification and redistribution (no permission needed).

## Files (54; 13 replaced Oct 18, 2026, see below)

Local assets are `*.webp` under this directory (512×512, lossy). Mapping from
staple name → slug lives in `src/lib/pantry-images.ts`.

Notable Commons sources include (non-exhaustive): Glass of milk; 6-Pack Chicken
Eggs (Evan-Amos, PD); Stick-of-butter-salted; Cooked white rice; Rolled oats;
Honeycrisp Apple / Banana-Single / Orange / Lemon / Blueberries (Evan-Amos);
Bowl of white sugar; Peanut butter glass; Distilled vinegar (Thai); Spaghetti /
uncooked pasta; Olive oil; Joghurt; Mayonnaise; Kikkoman soy sauce; Tuna can;
Bumbu dan Rempah spices; Semi-sweet chocolate chips; Pot of chicken broth; etc.

Unsplash CDN photos (crop via `images.unsplash.com`) used for several produce,
dairy, protein, and grocery-category tiles.

## Attribution note

CC BY / CC BY-SA Commons files retain author credit via this CREDITS file and
the upstream Commons file pages. Unsplash photos do not require attribution but
photographer credit on Unsplash is appreciated.
